YouTube Theme Options: Mathematics

Eight visual themes for math explainers (calculus, proofs, geometry, number theory, and similar). Each one shows a 16:9 thumbnail, an intro title card, and a lower third.

How to modify: each theme is a CSS block near the top of this file (for example .theme-chalk { ... }). Change --accent, --bg, or the font variables and the whole theme updates. Text on the demos (titles, kickers, names) is plain HTML and can be edited directly. Fonts are embedded in this file, so it works offline.
